# Token Optimizer

A comprehensive framework for optimizing token usage and performance.

## Project Structure

- **harness/**: Core optimization modules
- **configs/**: Configuration files for different optimization strategies
- **outputs/**: Generated reports, curves, CSVs, and plots
- **run_*.py**: Entry points for different optimization experiments

## Usage

Run the respective optimization experiments:

```bash
python run_baseline.py
python run_trim.py
python run_sweep.py
python run_cache.py
python run_routing.py
```
